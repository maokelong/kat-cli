# kat-sdk API

SDK wheel 版本：`0.1.1`

- `kat_sdk.providers.ftrace` — 将 tracefs 文本解码或复用为可通过 DataFusion SQL 查询的类型化关系。[详细 API](reference/providers/ftrace.md)
- `kat_sdk.providers.trace_streamer` — 打开已有 Trace Streamer SQLite，或调用指定解析器生成 SQLite，并执行只读查询。[详细 API](reference/providers/trace_streamer.md)
- `kat_sdk.helpers.demo.greeting` — 生成经过首尾空白规范化的中文问候语。[详细 API](reference/helpers/demo/greeting.md)
