# SDK Workflow 导航

需要选择已有 SDK Workflow、了解输入和输出时读取本目录。介绍随 kat Skill 交付，运行前按 [命令合同](../command-reference.md) 定位 CLI，再通过 inspection 核对已安装能力和参数；Skill 中有介绍不代表当前 SDK 已安装或包含该能力。

| 领域 | Workflow | 用途 |
| --- | --- | --- |
| demo | [demo-greeting](demo/greeting.md) | 调用公共库生成一行问候结果，验证执行与查询链路 |

执行分析使用 [kat-analyze](../../../kat-analyze/SKILL.md)。新增或修改 SDK Workflow 使用 [kat-dev-sdk](../../../kat-dev-sdk/SKILL.md)，同步维护本目录的领域介绍与导航。
