# 共同分析流程

一个 Session 对应一个任务目标和一份当前 Analysis Record，保存实际采用的方法、必要事实出处、分析进展和总报告。只有真实 Workflow 执行产生 Run；知识应用不产生 Run，报告树也不表达 AI 的思考或临时选择关系。命令与 JSON 字段以[公共命令合同](../../kat/references/command-reference.md)为准。

## 1. 明确目标或恢复任务

当前上下文已保留必要信息和成功保存结果时直接继续，不因汇总或上下文压缩本身机械重读。新任务只有 Session ID，或缺少继续所需信息时，用 `analysis show --session S` 恢复目标、revision、正文和材料概要，再按需读取材料或 Run；不先要求用户重述旧对话，不重新全局发现或执行。已有适用报告可直接只读交付。

明确没有记录时，可从已知目标和 `inspect session` 的现存 Run 建立记录，但不能还原未保存的旧结论。损坏或未知格式不当作无记录覆盖。只有 Run ID 且无法确定 Session 时请求所属 Session，不跨目录搜索。只读请求不创建记录、执行 Workflow 或归档材料。

## 2. 发现候选并理解适用条件

新任务先用 `kat inspect` 按 PACK 描述缩小范围，再查看相关 PACK 的 `inspect knowledge --pack P` 与 `inspect workflow --pack P` 用途列表。知识提供任务方法，Workflow 提供程序能力；先发现候选，再判断如何使用，不问用户应选知识还是 Workflow，也不先按任务类型排除其中一类。

根据摘要按需浏览候选知识正文、读取候选 Workflow detail 的参数合同，理解范围、输入和限制后选择。可以只用知识、只用 Workflow 或组合使用；不强制知识先行，不为覆盖两类而都采用，不加载全部正文或扫描 Provider。必要时依新发现扩大相关 PACK 范围，跨 PACK 使用仍沿用各自合同。

程序工作已有适用 Workflow 时优先复用；不因通用工具也能计算就重做。通用工具用于任务已授权的材料处理或没有适用 Workflow 的工作，不扩大外部访问、安装、执行或写入权限。

成功空列表、候选不适用、必需输入缺失和 inspection 失败分别处理。两类均无匹配时说明能力缺口，未经明确授权不转为 PACK 创作；缺输入时请求最小必要信息，不让用户替 AI 分类。发现失败不当作空列表，不静默换路或安装依赖。缺少 Python 导致 Workflow 无法发现时说明受限；仅在已发现知识明确足以处理现有材料、且任务不依赖程序能力时继续纯知识分析，不能据此宣称不存在适用 Workflow。所需能力无法确认时停止并说明阻碍。

## 3. 组织使用并按事实继续

确定目标与可用能力后，新任务创建 Session，用 `analysis save --session S --expected-revision 0 --file goal.json` 保存目标，成功后才采纳知识或执行 Workflow。能力浏览不建立任务记录；同一目标的追问、补证和不同能力共用该 Session，独立新目标新建 Session。

采纳知识按[知识读取与快照](knowledge-flow.md)取得已提交原文；执行、查询或解释 Run 按[Workflow 取证](workflow-flow.md)操作。用户材料和已授权工具取得的事实不必变成 Run Output；它们不是已归档的 Query 或知识快照，正文保留真实出处与恢复限制。方法和 Guide 不代替事实证据。

依据实际材料形成判断，区分事实、推断、范围与缺口。证据不足时，围绕缺口继续发现、补问或取证，不预先固定调用序列。已形成的必要进展及时保存，成功后再供后续判断复用。纯知识任务直接保存 report；实际 Run 的必要解释保存为该 Run 的 content，不为知识或每次工具使用创建占位节点。

## 4. 保存、核对与交付

每次 `analysis save` 使用最近已核对的 revision；材料操作的回执只有在 `previous_revision` 等于先前已核对值时，才可直接沿用新 revision，否则先 `analysis show` 核对并发修改。冲突不只换数字重提；响应不确定先确认实际记录，不盲目重复保存、采纳、归档或重跑 Workflow。失败不能覆盖上次完整内容。

保存的正文须自足地说明必要结论、依据、出处、取证原因和限制，不依赖旧对话的“如上所述”，不增加选择记录、依赖字段或模型内部推理过程。省略内容保持原样；修改方法、目标或某个判断后，AI 核对受影响正文与总报告，程序不自动判断有效性。

汇总围绕用户问题处理范围差异、矛盾、重叠证据与缺口，优先复用当前上下文中已保存且适用的正文，缺信息才读取记录。交付前读取[结果契约](result-contract.md)并保存总报告；成功 Response 已确认保存，无需额外回读。保存未确认时说明判断与保存状态，不承诺新报告可恢复。证据足够即停止。
