# Summarize Ftrace Events 结果解释

`event_count` 是输入文本中成功解析的同名事件记录数，范围是整份输入，没有按时间、
线程或 CPU 筛选。它表示记录条数，不是持续时长、发生频率或性能影响；跨 trace 比较
数量前需要可比的采集范围与配置。

可据此识别哪些事件类别值得进一步分析。类别未出现或结果为空，只表示没有对应的
已解析记录，不能证明系统未发生该行为，也不能证明采集完整。

结果没有事件时序、CPU/线程分布或采集完整性证据。需要判断切换间隔、热点或丢失时，
应使用提供这些证据的可用 Workflow；本 PACK 的这份汇总不足以回答时，应明确缺口，
不能从计数反推时间线或原因。
