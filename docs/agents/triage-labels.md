# Triage labels

工程技能使用五个标准 triage 角色。下表定义这些角色在本仓库中的实际 label。

| 技能角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分定义，可由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不会处理 |

技能提及某个 triage 角色时，使用对应的 GitHub label。
