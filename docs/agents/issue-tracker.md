# Issue tracker: GitHub

本仓库的 issue 和 PRD 位于 `maokelong/kat-rs` 的 GitHub Issues，使用已连接的 GitHub Connector 操作。

## 约定

- 创建、读取、列出、评论、更新、标记和关闭 issue 时，使用 GitHub Connector 对应操作。
- 仓库身份固定为 `maokelong/kat-rs`，并可由 `git remote -v` 核验。
- 技能要求“发布到 issue tracker”时，创建 GitHub issue。
- 技能要求“读取相关 ticket”时，读取 issue 正文、评论和 labels。
- 修改 labels 时保留未要求移除的现有 labels。
- 关闭 issue 时记录原因；不静默改写历史。

## Pull requests as a triage surface

**PRs as a request surface: no.**

外部 PR 默认不进入与 issue 相同的 triage 队列。
