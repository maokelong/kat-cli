# Domain docs

工程技能探索和修改本仓库前，应按以下规则消费领域文档。

## 开始探索前

- 完整读取仓库根目录的 `CONTEXT.md`。
- 阅读 `docs/adr/` 中与当前工作相关的 ADR。
- 若这些路径不存在，继续工作，不为缺失本身创建占位文档。

## 布局

本仓库采用 single-context 布局：

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```

## 使用领域词汇

issue、设计、测试和代码中涉及领域概念时，使用 `CONTEXT.md` 定义的术语，不漂移到其中明确排除的同义词。

若所需概念尚未定义，先判断是否引入了项目并不需要的新语言；确有领域缺口时，记录并交由 domain-modeling 流程处理。

## 处理 ADR 冲突

产出若与现有 ADR 冲突，必须明确指出冲突及重新讨论的理由，不得静默覆盖已有决定。
