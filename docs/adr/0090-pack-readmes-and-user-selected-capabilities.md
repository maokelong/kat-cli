# PACK 自带使用说明，分析前由用户选择能力

跟踪：[Issue #334](https://github.com/maokelong/kat-cli/issues/334)。

其他团队持续发布能力后，自动执行不能让用户理解有哪些方案及其区别。PACK 根 README 作为随包使用导航，由 owner 维护；作者 Skill 在创建和能力更新时生成事实区并维护场景说明，也能为已有 PACK 单独生成文档。事实来自既有 inspection，不建立集中知识索引或另一套执行合同。SDK wheel 携带使用说明，但开发 API 文档仍依 ADR-0086 排除在 wheel 外。

问题分析枚举当前发现范围内的知识入口与 Workflow 摘要，展示全部相关且允许用户选用的候选，并等待用户选择后才采纳知识或执行。唯一候选也等待；明确指定目标或明确授权自动选择视为已有选择。已选方案内的取证不逐步重选，新增实质不同的方向再选。已有任务恢复与只读报告交付沿用已选方法。

本决定替代 ADR-0014 中候选明确时自动执行的规则，并替代分析 Skill 中找到知识后不再发现 Workflow 的顺序。知识入口与 Workflow 共同参与发现，不改变二者方法与程序的职责。调用标志继续约束展示与自动选用；作者按发布意图填写，不再强制新入口同时禁用两种选择方式。

浏览不产生 Session 或方法采纳。能力范围仍由当前部署和显式外部目录决定，未安装的远端能力不在本次交付范围。README 不覆盖 Workflow 输入合同、Guide 快照或外部操作授权。
